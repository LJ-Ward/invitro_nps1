# invitro_nps1
R code associated with data preprocessing for published paper "In vitro metabolomics for the characterization of drugs of abuse and new psychoactive substances in SH-SY5Y cells" by authors: Monti MC, Stalberga D, Green H, Ward LJ*, Elmsjö A*. 2026. Environmental Toxicology and Pharmacology. https://doi.org/10.1016/j.etap.2026.105022. 

xcms.R script for preprocessing using XCMS and CAMERA packages to .mzML converted raw data. Script setting are contained with "settings_RP.yaml" and "settings_HILIC.yaml", these can be used to edit settings for data preprocessing as necessary. Output of script is an excel sheet.
